Metric definitions
•Booked value: sum booked_amount_inr, all statuses
•Delivered value: sum booked_amount_inr where status=DELIVERED (refunds not subtracted again)
•Refunds: sum refund_amount_inr (RETURNED rows only)
•AOV: sum booked / order count of the same population
•Effective discount: sum discount_amount_inr / sum gross_amount_inr x 100
•Return rate: RETURNED orders / (DELIVERED + RETURNED orders) x 100
•Cancellation rate: CANCELLED orders / all orders x 100
•MoM change: (booked this month - booked prior month) / booked prior month x 100
•Exception rule: month x region cell with return rate > overall return rate + 1.5 percentage points
Caveats
•Synthetic data (seed 20261029); not real Shopsy trading.
•Booked value is not revenue: it includes returned (₹16.5 Cr), cancelled and open orders. Refunds (₹16.5 Cr) and shipping fees (₹1.7 Cr) are reported separately.
•25,905 orders (4.1%) were still READY_TO_SHIP at the 30 Sep 2026 cutoff, spread evenly across months (3.9%–4.2% per month), so final delivered and return figures may move.
•Return-rate denominator is DELIVERED + RETURNED orders (5,69,389); as a share of all orders it is 9.0%.
•Only 8 cities appear in the data, so city-level conclusions are limited.
